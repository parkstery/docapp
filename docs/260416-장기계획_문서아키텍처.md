---

## 1. 배경·목표

- **제품 목표**: 일상 기록은 텍스트 중심으로 빠르게, 필요 시 **이미지 포함 보고서**로 읽기 좋게, Cursor 등에는 **Markdown 가독성**으로 활용.
- **기술적 과제**: 본문이 Markdown / HTML(TipTap) / contentEditable 문자열 등으로 흩어져 유지보수·외부 도구(Notion 등) 호환이 어렵다.
- **원칙**: **Editor(작성) / Renderer·Export(표현)** 분리. **Markdown은 출력 채널 중 하나**로 두고, 저장의 단일 진실을 무리하게 Markdown에 두지 않는다.
